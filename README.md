# yier_desktop_pet
一二桌宠

### 桌面宠物

- 透明无边框、始终置顶，可拖动和隐藏。
- 系统托盘支持显示宠物、打开管理页和退出。
- 点击小熊可在站立与坐姿间切换。
- 玩耍、投喂、摸摸、休息互动。
- 待机、站坐、玩耍、摸摸、投喂和奔跑逐帧动画。
- 音符、星光、食物、爱心和地面阴影效果。
- 鼠标经过时有轻微视差反馈。
- 自动奔跑开关及 10 秒、20 秒、30 秒、1 分钟、5 分钟间隔。
- 奔跑只发生在透明窗口内部，不移动桌面窗口。
- 宠物窗口可快速新增事件提醒、查看未读提醒并标记已读。
- AI智能聊天功能

### 管理面板

- 本地注册、登录和退出，数据按账号隔离。
- 今日工作任务：日期、优先级、完成状态和删除。
- 事件提醒：日期、时间、备注和删除。
- 陪伴日志、互动记录和今日小结。
- 晚间日报提醒、久坐提醒和系统铃声测试。
- 已触发提醒历史，支持按日期与类型筛选。
- 自动奔跑开关和间隔设置。
- AI模型配置

### 本机通知

- 到点发送 macOS/Windows 系统通知。
- 未读数量、Dock/任务栏角标与注意力提示。
- Windows 任务栏闪烁，macOS Dock 角标。
- 提醒触发后写入本地历史记录。
